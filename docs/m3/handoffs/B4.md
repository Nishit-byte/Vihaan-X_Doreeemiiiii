# Handoff B4 — ExaminerPanel static layout

## Project in one paragraph
VivaVoce is an adaptive spoken-plus-text technical viva examiner built for the Vihaan hackathon (24-hour build). A student provides a GitHub repo or research paper PDF, and VivaVoce conducts an adaptive viva climbing a 4-level Bloom's taxonomy ladder (Recall, Comprehension, Analysis, Evaluation with live pytest sandbox verification) evaluated by a fluency-blind rubric (accent and grammar get 0% weight). M3 owns the voice pipeline: STT, TTS, latency-hiding fillers, push-to-talk browser recording, audio playback, and the reactive examiner UI panel.

export default function ExaminerPanel(props: ExaminerPanelProps): JSX.Element
