# Handoff A5 — voice_router + dev_server mock backend

## Project in one paragraph
VivaVoce is a spoken-plus-text technical viva examiner built for the Vihaan hackathon (Education track). It conducts an adaptive spoken technical examination of a student based on their GitHub repository or research paper PDF, climbing a 4-level Bloom's taxonomy ladder (L1 Recall to L4 Evaluation/Mutation with live code verification) and producing a fluency-blind assessment. M3 owns the voice pipeline: low-latency Groq Whisper speech-to-text with domain vocabulary biasing, Edge-TTS audio synthesis with Indian English voices, and pre-cached audio fillers for sub-200ms audio response latency.

## Public interface as implemented

### `voice.voice_router` (`backend/voice/__init__.py`)
Mounted by M1 with `app.include_router(voice_router, prefix="/api/voice")`:
- `GET /health` -> `{"stt_ready": bool, "tts_provider": "edge-tts", "fillers": int}`
- `GET /fillers` -> `list[{"id": str, "text": str, "audio_base64": str}]`
- `POST /transcribe` body `{"audio_base64": str, "mime_type": Optional[str], "lang": Optional[str], "domain_terms": Optional[list[str]]}` -> `{"text": str, "ms": int}` (HTTP 400 on invalid base64)
- `POST /speak` body `{"text": str}` -> `{"audio_base64": str, "ms": int}`

### `voice.dev_server` (`backend/voice/dev_server.py`)
Run via `python -m uvicorn voice.dev_server:app --port 8000`:
- `GET /` -> `{"service": "VivaVoce Voice Dev Server", "status": "running"}`
- `GET /api/dev/start?session_id=<optional>` -> `TurnResponse` dict (verdict `"start"`, depth 1)
- `POST /api/viva/turn` body `{"session_id": str, "student_text": Optional[str], "audio_base64": Optional[str], "audio_mime": Optional[str], ...}` -> `TurnResponse` dict (evaluates verdict, advances question 1..5, synthesizes audio, HTTP 400 on invalid base64)
- `GET /api/voice/*` -> mounted from `voice_router`

Differences from CONTEXT §5: None. All endpoints, parameters, models, CORS origins, and response shapes match CONTEXT §5.5 and §5.6.
