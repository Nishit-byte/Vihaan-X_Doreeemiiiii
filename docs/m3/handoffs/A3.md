## What this task did
- Fully implemented `backend/voice/audio_utils.py` adhering strictly to CONTEXT §5.3 and TASKS A3:
  - `detect_audio_format(audio_bytes: bytes) -> str`:
    - Fast magic-byte sniffing without external dependencies.
    - Matches WebM (`1A 45 DF A3`), WAV (`RIFF....WAVE`), Ogg (`OggS`), MP4 (`ftyp` at offset 4), and MP3 (either `ID3` container or MPEG frame sync header `0xFF` followed by `0xFB`/`0xF3`/`0xF2`).
    - Returns `'unknown'` for unrecognised, truncated (< 2 bytes), or non-audio binary data.
  - `is_probably_silent_or_too_short(audio_bytes: bytes, fmt: str | None = None) -> bool`:
    - Immediate bypass: empty bytes or payloads under 2048 bytes return `True` instantly.
    - For WAV audio, inspects duration (< 0.3 s -> `True`) and calculates RMS audio power using stdlib `wave` + `array` (0 numpy). If RMS < -40.0 dBFS, returns `True`.
    - Handles corrupted/unreadable WAVs gracefully by returning `True`.
    - Non-PCM16 or non-WAV formats with size >= 2 KB return `False`. NEVER raises.
  - `trim_silence(wav_bytes: bytes, threshold_db: float = -40.0, pad_ms: int = 150) -> bytes`:
    - Trims leading and trailing silence from 16-bit PCM WAV audio using 10 ms windowed RMS checks.
    - Applies `pad_ms` (150 ms) margin around active audio to prevent clipping word edges.
    - Completely silent WAVs, non-PCM16 WAVs, non-WAV formats, or corrupt streams are returned unedited. NEVER raises.
  - `normalize_audio(audio_bytes: bytes, mime_type: str | None = None) -> tuple[bytes, str]`:
    - Detects format, applies `trim_silence` if WAV, and returns tuple `(bytes, filename)` (e.g. `(b"...", "answer.webm")`).
    - Gives proper filename extensions required by Groq Whisper API.
  - `FILLER_TEXTS`: Exactly 3 predefined phrases per CONTEXT §5.3:
    1. `"Let me check that line..."`
    2. `"Interesting, checking your implementation..."`
    3. `"Hmm, give me a second to think about that."`
  - `warm_filler_cache() -> None`:
    - Creates `filler_cache/filler_1.mp3`..`filler_3.mp3` and `fillers.json` in `FILLER_CACHE_DIR` via `tts_service.synthesize_speech`.
    - Skips existing valid files; runs in < 5 ms when cached. NEVER raises.
  - `get_all_fillers() -> list[dict]` & `get_filler_audio() -> str`:
    - Lazily loads MP3s and metadata from disk on first call and caches them in memory.
    - Returns list of `{"id": "filler_X", "text": "...", "audio_base64": "..."}`.
    - `get_filler_audio` returns random pre-cached filler as base64 string (`""` if none).
- Ran `warm_filler_cache` to generate the 3 filler MP3 clips into `backend/voice/filler_cache/` so offline demos work out-of-the-box.
- Verified integration with `backend/main.py` adapter endpoint `/api/filler-audio`, which now successfully serves pre-cached audio fillers.

2. Silence Trimming on Synthetic Tone WAV (0.5s silence + 1.0s 440 Hz tone + 0.5s silence):
```powershell
backend\.venv\Scripts\python.exe -c "
import sys; sys.path.insert(0, 'backend')
import io, math, wave, array
from voice import audio_utils

framerate = 16000
buf = io.BytesIO()
with wave.open(buf, 'wb') as wf:
    wf.setnchannels(1)
    wf.setsampwidth(2)
    wf.setframerate(framerate)
    wf.writeframes(b'\x00\x00' * int(framerate * 0.5))
    tone = [int(16000.0 * math.sin(2.0 * math.pi * 440.0 * i / framerate)) for i in range(framerate)]
    wf.writeframes(array.array('h', tone).tobytes())
    wf.writeframes(b'\x00\x00' * int(framerate * 0.5))
orig_wav = buf.getvalue()

trimmed_wav = audio_utils.trim_silence(orig_wav, threshold_db=-40.0, pad_ms=150)
with wave.open(io.BytesIO(trimmed_wav), 'rb') as wf:
    dur = wf.getnframes() / wf.getframerate()
    samples = array.array('h')
    samples.frombytes(wf.readframes(wf.getnframes()))

assert math.isclose(dur, 1.30, abs_tol=0.05)
assert len(trimmed_wav) < len(orig_wav)
rms = math.sqrt(sum(s * s for s in samples) / len(samples))
assert rms > 5000
print(f'PASS trim_silence: 2.0s ({len(orig_wav)} bytes) -> {dur:.2f}s ({len(trimmed_wav)} bytes), RMS={rms:.1f}')
"
```
Output:
`PASS trim_silence: 2.0s (64044 bytes) -> 1.30s (41644 bytes), RMS=9922.4`
