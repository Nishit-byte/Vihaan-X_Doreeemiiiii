# Handoff B5 — Voice orb animation

## Project in one paragraph
VivaVoce is an adaptive spoken-plus-text technical viva examiner built for the Vihaan hackathon (24-hour build). A student provides a GitHub repo or research paper PDF, and VivaVoce conducts an adaptive viva climbing a 4-level Bloom's taxonomy ladder (Recall, Comprehension, Analysis, Evaluation with live pytest sandbox verification) evaluated by a fluency-blind rubric (accent and grammar receive 0% weight). M3 owns the voice pipeline: STT, TTS, latency-hiding fillers, push-to-talk browser recording, audio playback, and the reactive examiner UI panel.

## What this task did
- Fully implemented `VoiceOrb` inside `frontend/src/components/ExaminerPanel.tsx` per CONTEXT §5.9 & TASKS B5:
  - Props: `state` (`'idle' | 'listening' | 'thinking' | 'speaking' | 'done'`), `levelSource?: () => number`, `size?: number`, `className?: string`.
  - High-DPI Canvas rendering using `window.devicePixelRatio || 1` with logical dimension scaling and `ctx.setTransform(dpr, 0, 0, dpr, 0, 0)`.
  - Smoothed scale formula: `smoothedLevel += (targetLevel - smoothedLevel) * 0.18` (lerp), driving dynamic scale `1 + smoothedLevel * 0.35` (spec exact: `1 + level * 0.35`).
  - Implemented exact per-state visual designs:
    - **idle**: Slow sinusoidal breathing (period ~3.5s) in slate & indigo (`#6366f1` / `#3730a3` / `#0f172a`), subtle ambient radial glow, and faint orbital ring.
    - **listening**: Vivid emerald core (`#34d399` / `#059669` / `#064e3b`) reacting dynamically to mic amplitude, emitting dual reactive emerald shockwave rings (`rgba(0, 220, 130, ...)`) and specular highlight.
    - **thinking**: Warm amber core (`#fbbf24` / `#d97706` / `#78350f`) with gentle breathing pulse surrounded by an outer rotating dashed ring (`setLineDash([8, 6])` rotating at `time * 0.0024`) plus a counter-rotating dashed accent ring.
    - **speaking**: Vibrant violet & indigo core (`#c084fc` / `#818cf8` / `#4f46e5`) with 3 concentric expanding ripple waves (`rgba(139, 92, 246, ...)`) reacting to playback audio level.
    - **done**: Calm static emerald orb (`#34d399` / `#059669`) with serene halo ring and crisp central white checkmark.
  - Zero React state updates per animation frame: all animation parameters, timestamps, and levels are computed locally in the `requestAnimationFrame` loop.
  - Lifecycle safety: loop cleanly cancels on component unmount (`cancelAnimationFrame`).
  - Accessibility (`prefers-reduced-motion`): evaluates `window.matchMedia('(prefers-reduced-motion: reduce)')` and draws a static state-colored orb without scheduling continuous `rAF` loops.
- Replaced the placeholder in `ExaminerPanel.tsx` with `<VoiceOrb />`, adding `levelSource?: () => number` to `ExaminerPanelProps` and forwarding it seamlessly.
- Updated the dev harness (`frontend/src/dev/examinerDev.tsx`):
  - Removed `h-screen`, `w-screen`, and `overflow-hidden` clipping on the outer container to allow natural, full vertical page scrolling (`overflow-x-hidden`, responsive height).
  - Main split view (65% Workspace, 35% ExaminerPanel) given a clean, comfortable height (`h-[620px]`).
  - Dev Controls section (`#dev-controls`) is permanently rendered directly below the split view with zero hiding/collapsing restrictions, organized into responsive card grids (`grid-cols-1 md:grid-cols-2 xl:grid-cols-4`).
  - Added dedicated Section 1: `🔮 Task B5: Voice Orb Animation Controls`:
    - State switcher buttons (`auto`, `idle`, `listening`, `thinking`, `speaking`, `done`).
    - Level source switcher:
      - `🎚️ Fake Level Slider` with interactive 0 to 1 range slider (step 0.01) displaying live value and quick percentage presets (0%, 25%, 50%, 75%, 100%).
      - `🎙️ Use mic level (B2 getInputLevel)` connecting live microphone audio directly to the orb.
      - `🔊 Use playback level (B3 getLevel)` connecting live MP3/TTS audio directly to the orb.
    - Live numeric level and effective level readout with dynamic scale feedback (`1 + level * 0.35`).
    - Dedicated 60fps `LiveOrbLevelMeter` and standalone 130px `VoiceOrb` preview card alongside the live panel orb.
