# Handoff A4 — STT service (Groq Whisper)

## Project in one paragraph
VivaVoce is a spoken-plus-text technical viva examiner built for the Vihaan hackathon (Education track). It conducts an adaptive spoken technical examination of a student based on their GitHub repository or research paper PDF, climbing a 4-level Bloom's taxonomy ladder (L1 Recall to L4 Evaluation/Mutation with live code verification) and producing a fluency-blind assessment. M3 owns the voice pipeline: low-latency Groq Whisper speech-to-text with domain vocabulary biasing, Edge-TTS audio synthesis with Indian English voices, and pre-cached audio fillers for sub-200ms audio response latency.

## What this task did

- Fully implemented `backend/voice/stt_service.py` adhering strictly to CONTEXT §5.4 and TASKS A4:
  - `transcribe_audio(audio_bytes: bytes, lang: str | None = "en", domain_terms: list[str] | None = None, mime_type: str | None = None) -> str` (async):
    - **Pre-flight audio checks**: Calls `audio_utils.is_probably_silent_or_too_short(raw_bytes, fmt=mime_type)`. If empty, too short (< 2 KB), or silent WAV, returns `""` immediately with 0 API calls.
    - **Audio normalization**: Uses `audio_utils.normalize_audio` for magic byte detection, PCM16 WAV silence trimming, and proper extension mapping (`answer.webm`, `answer.mp3`, `answer.wav`). Re-checks normalized audio before dispatch.
    - **API key validation**: Safely checks `GROQ_API_KEY`. If empty, logs a warning once (`_warned_missing_key = True`) and returns `""` without raising.
    - **Domain conditioning**: Uses `build_domain_prompt(domain_terms)` to prepare a Whisper conditioning prompt with code-switching Hinglish context and technical identifiers.
    - **Groq client integration**: Calls `groq.AsyncGroq(api_key=...).audio.transcriptions.create(file=(filename, norm_bytes), model=GROQ_STT_MODEL, prompt=..., language=lang, temperature=0, response_format='json')`. Omits `language` if `lang is None`. Reuses cached `AsyncGroq` client per key.
    - **Timeout & retry resilience**: Bounded by `STT_TIMEOUT_S` (10s default). Retries once on timeout (`asyncio.TimeoutError`, `groq.APITimeoutError`) or 5xx server errors (`groq.APIStatusError` / `httpx.HTTPStatusError` with `status_code >= 500`). On 4xx client errors (e.g. 401 Unauthorized for bad key), aborts immediately without retry.
    - **Security & error suppression**: NEVER raises exceptions under any failure mode. NEVER logs the API key (all exception strings are scrubbed with `_sanitize_log_message`).
    - **Hallucination filter**: Implements `_filter_hallucinations(transcript)` to eliminate known Whisper silence artifacts (`"thank you for watching"`, `"subtitles by"`, `"you"`, `"."`, `"thanks"`, etc.) when they constitute the entire transcript. Never strips these words from valid multi-word answers.
  - `build_domain_prompt(domain_terms: list[str] | None = None) -> str`:
    - Base prompt establishes Hinglish style context: `"Technical viva. The student may mix Hindi and English, like 'haan, toh basically yeh function cosine similarity return karta hai'."`
    - Appends up to 40 unique domain identifiers from `domain_terms`.
    - Strictly caps total prompt length at <= 590 characters, safely under Whisper's 600 character prompt window.
    - Gracefully handles `None`, empty lists, and comma-separated strings.
  - `transcribe_audio_sync(audio_bytes: bytes, lang: str | None = "en", domain_terms: list[str] | None = None, mime_type: str | None = None) -> str`:
    - Synchronous wrapper for scripts. Safely checks if an event loop is already running in the current thread: if active, dispatches via `ThreadPoolExecutor` worker with `asyncio.run`; if inactive, calls `asyncio.run` directly. NEVER raises.
- Verified end-to-end integration with M1's `main.py` adapter `_invoke_m3_stt`.
