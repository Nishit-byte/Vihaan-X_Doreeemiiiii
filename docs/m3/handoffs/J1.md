## Project in one paragraph
VivaVoce is an adaptive spoken-plus-text technical viva examiner built for the Vihaan hackathon (Education track, 24-hour build). A student provides a GitHub repo (Mode A) or research paper PDF (Mode B), and VivaVoce conducts an adaptive technical examination climbing a 4-level Bloom's taxonomy ladder (L1 Recall to L4 Evaluation/Mutation with live pytest sandbox verification) evaluated by a fluency-blind rubric (accent and grammar receive 0% weight). M3 owns the voice pipeline: low-latency Groq Whisper speech-to-text with domain vocabulary biasing, Edge-TTS audio synthesis with Indian English voices (`en-IN-PrabhatNeural`), pre-cached latency-hiding filler audio clips for sub-200ms audio response latency, and the reactive examiner frontend panel.
