# Handoff A2 — TTS service (edge-tts + fallback + speakable text)

## Project in one paragraph
VivaVoce is a spoken-plus-text technical viva examiner built for the Vihaan hackathon (Education track). It conducts an adaptive spoken technical examination of a student based on their GitHub repository or research paper PDF, climbing a 4-level Bloom's taxonomy ladder (L1 Recall to L4 Evaluation/Mutation with live code verification) and producing a fluency-blind assessment. M3 owns the voice pipeline: low-latency Groq Whisper speech-to-text with domain vocabulary biasing, Edge-TTS audio synthesis with Indian English voices, and pre-cached audio fillers for sub-200ms audio response latency.

## What this task did
- Fully implemented `backend/voice/tts_service.py` adhering strictly to CONTEXT §5.2 and TASKS A2:
  - `synthesize_speech(text: str) -> str` (async):
    - Primary TTS engine: Microsoft Edge TTS via `edge_tts.Communicate(text, voice, rate=TTS_RATE).stream()`, collecting audio chunks to an MP3 byte stream. Configured defaults: voice `en-IN-PrabhatNeural`, rate `+0%`.
    - Fallback TTS engine: ElevenLabs HTTP POST (`https://api.elevenlabs.io/v1/text-to-speech/{voice_id}`) with header `xi-api-key` and model `eleven_flash_v2_5`. Only invoked if edge-tts fails AND both `ELEVENLABS_API_KEY` and `ELEVENLABS_VOICE_ID` are configured.
    - In-memory LRU cache: 128 entries maximum, keyed by `(voice, rate, speakable_text)`, returning cached base64 MP3 in ~1 ms with zero network calls.
    - Timeout protection: Each provider call is bounded with `asyncio.wait_for(..., timeout=TTS_TIMEOUT_S)`.
    - Structured logging: Logs provider, voice/voice_id, status (success/failed), latency in milliseconds, and audio payload bytes.
    - Fault-tolerance: Function NEVER raises exceptions; returns `""` on total failure.
    - Immediate bypass: Empty or whitespace-only text returns `""` instantly with 0 network calls.
  - `synthesize_speech_sync(text: str) -> str`:
    - Robust synchronous wrapper around `synthesize_speech` for scripts. Automatically handles both threads with no event loop (`asyncio.run`) and threads with already-running event loops (`ThreadPoolExecutor` worker). NEVER raises.
  - `to_speakable(text: str) -> str`:
    - Strips markdown syntax (backticks, asterisks, hashes, blockquotes, markdown links).
    - Removes empty function call parentheses `()` after identifiers (`compute_cosine_similarity() -> compute_cosine_similarity`).
    - Normalizes line ranges (`L12-L20`, `lines 12-20`, `line 12-20`, `L12 - L20` -> `lines 12 to 20`).
    - Explicitly preserves technical terminology and Bloom ladder terms without corruption (e.g. `L4 Evaluation` and `Python 3.11` are NOT mangled).
    - Converts snake_case underscores to spaces, guaranteeing 0 underscores in speech output.
    - Collapses consecutive whitespace and caps length at ~600 characters on sentence or word boundaries.
  - `build_spoken_text(ack_text: str, question_text: str) -> str`:
    - Seamlessly merges examiner acknowledgment and question strings with proper punctuation (`ack. question`).
    - Gracefully handles empty acknowledgments or empty questions and applies `to_speakable` sanitization.
- Verified end-to-end integration with M1's `main.py` adapter `_invoke_m3_tts`.
- Installed `python-multipart` into local virtual environment (`backend/.venv`) so that `backend/main.py` imports without errors (per requirements.txt).

2. Speech Synthesis, Cold vs Cached Latency, and MP3 Frame Validation:
```powershell
backend\.venv\Scripts\python.exe -c "
import sys; sys.path.insert(0, 'backend')
import asyncio, base64, os, time
from pathlib import Path
from voice import tts_service

sample_q = 'In lines 12-20, can you explain how `compute_cosine_similarity()` calculates the angle between vector embeddings in Python 3.11?'
tts_service._clear_cache()

# Cold call
t0 = time.perf_counter()
b64_cold = asyncio.run(tts_service.synthesize_speech(sample_q))
cold_ms = (time.perf_counter() - t0) * 1000.0

# Cached call
t0 = time.perf_counter()
b64_cached = asyncio.run(tts_service.synthesize_speech(sample_q))
cached_ms = (time.perf_counter() - t0) * 1000.0

# Empty text
t0 = time.perf_counter()
b64_empty = asyncio.run(tts_service.synthesize_speech(''))
empty_ms = (time.perf_counter() - t0) * 1000.0

audio_bytes = base64.b64decode(b64_cold)
is_frame_sync = len(audio_bytes) >= 2 and audio_bytes[0] == 0xFF and (audio_bytes[1] & 0xE0) == 0xE0

temp_file = Path(os.environ.get('TEMP', r'C:\Windows\Temp')) / 'vivavoce_a2_verification.mp3'
with open(temp_file, 'wb') as f:
    f.write(audio_bytes)

print(f'Cold call latency: {cold_ms:.1f} ms')
print(f'Cached call latency: {cached_ms:.2f} ms')
print(f'Empty text latency: {empty_ms:.3f} ms (result: {b64_empty!r})')
print(f'Decoded audio size: {len(audio_bytes)} bytes')
print(f'MP3 frame sync header: {is_frame_sync} (first 4 bytes: {audio_bytes[:4].hex()})')
```
