# Handoff A5 — Demo loader + cache wiring

## Project in one paragraph
VivaVoce is a spoken-plus-text technical viva examiner for GitHub code repositories (Mode A) and research paper PDFs (Mode B) climbing Bloom's taxonomy from recall up to live sandbox mutation fixes. ## What this task did
- Fully implemented `backend/ingestion/demo_loader.py` per CONTEXT §5.5:
  - `is_demo_source(url_or_name: str) -> bool`: Accurately identifies demo repository sources across all variants: canonical `DEMO_REPO_URL` with or without `.git`, with or without trailing slash, scheme-less forms, case-insensitively, with surrounding whitespace, and the word `"demo"` (case-insensitive: `"demo"`, `"DEMO"`, `"Demo"`). Rejects non-demo URLs and invalid inputs.
  - `load_demo_repo() -> tuple[RepoIndex, dict[str, list[OwnedSymbol]], list[AuthorStat]]`: Parses `sample_repo_index.json` and `sample_repo_authors.json` from `DEMO_CACHE_DIR`, caches the parsed Pydantic objects in memory after the first load, and returns safe deep copies (`model_copy(deep=True)`) so caller mutations cannot corrupt cached state. Sets `from_cache=True` and makes zero network calls.
  - `materialize_demo_repo() -> str`: Clones `sample_repo.bundle` into a deterministic directory (`WORK_DIR/studysync`) once per process. Verifies folder integrity (`.git` and key files exist); reuses the directory instantly on subsequent calls (< 1 ms); cleanly recovers and re-materializes if the directory is missing, deleted, or corrupted. Employs Windows-safe non-interactive subprocess flags (`stdin=subprocess.DEVNULL`, `GIT_TERMINAL_PROMPT=0`, `GCM_INTERACTIVE=never`, `GIT_ASKPASS=echo`) with a 30 s timeout to guarantee it never hangs.
  - `load_demo_challenge() -> dict`: Loads `sample_repo_challenge.json` from `DEMO_CACHE_DIR`, caches in memory, and returns a safe deep copy (`copy.deepcopy`) protecting cached challenge state from caller mutation.
- Wired demo caching into `clone_and_index_repo(github_url: str, *, use_cache: bool = True) -> RepoIndex` in `backend/ingestion/repo_parser.py`:
  - When `use_cache=True` and `is_demo_source(github_url)` is True, immediately loads the index from `demo_loader` (< 4 ms), materializes the local repo path via `materialize_demo_repo()`, sets `repo_index.local_path`, and returns without touching the network or calling `clone_repo`.
  - Strictly preserved all existing functionality in `repo_parser.py`, including A2's AST hardening (`SyntaxError`, `ValueError`, `RecursionError`, `MemoryError`).
- Implemented comprehensive test suite in `backend/tests_m2/test_a5_demo_loader.py` with 9 test cases covering URL variants, timing thresholds (< 0.2 s), zero-network enforcement (monkeypatching `socket.socket`), cache mutation isolation, directory lifecycle/recovery, challenge loading, and cache-disabled fallback behavior.

## Public interface as implemented
- `ingestion.demo_loader.is_demo_source(url_or_name: str) -> bool`
  Accepts `DEMO_REPO_URL` with/without `.git`, with/without trailing slash, case/whitespace insensitive, and `"demo"`.
- `ingestion.demo_loader.load_demo_repo() -> tuple[RepoIndex, dict[str, list[OwnedSymbol]], list[AuthorStat]]`
  Loads cached `RepoIndex` (`from_cache=True`), `dict[str, list[OwnedSymbol]]`, and `list[AuthorStat]` with in-memory caching and safe deep copies. Target < 0.2 s, zero network calls.
- `ingestion.demo_loader.materialize_demo_repo() -> str`
  Clones `sample_repo.bundle` into deterministic `WORK_DIR/studysync` using Windows-safe git subprocess flags; reuses if valid, recovers if deleted; returns absolute path.
- `ingestion.demo_loader.load_demo_challenge() -> dict`
  Loads `sample_repo_challenge.json` with in-memory caching and safe deep copies.
- `ingestion.repo_parser.clone_and_index_repo(github_url: str, *, use_cache: bool = True) -> RepoIndex`
  Wired with demo cache: if `use_cache=True` and `is_demo_source(github_url)`, returns cached `RepoIndex` with `local_path = materialize_demo_repo()`.
