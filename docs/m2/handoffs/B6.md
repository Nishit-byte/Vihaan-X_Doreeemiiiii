## What this task did
- Implemented `backend/replay/store.py` (`ReplayStore`) matching CONTEXT §5.8 and TASKS B6:
  - Records API interactions to `session.jsonl` with `(method, path, normalized_path, status, body)`.
  - Implemented recursive audio extraction: inspects all dictionaries and lists at arbitrary depth for `audio_base64` keys; decodes base64 (supporting raw base64 and `data:audio/...;base64,` URLs), writes raw bytes to `replay/audio/<n>.mp3` with sequential indexing, and substitutes `@audio:<n>.mp3` in the recorded body.
  - Implemented recursive audio rehydration: restores `@audio:<filename>` tokens into complete base64 strings during replay playback.
  - Implemented FIFO queuing per `(method, normalized_path)` tuple with sequential playback cursors.
  - Implemented `normalize_path`: strips query strings and trailing slashes, and parameterizes `/api/report/<id>` to `/api/report/{id}`.
  - Implemented `reset()` (rewinds cursors and reloads sessions), `clear()` (purges `session.jsonl` and all audio files), and `status()` (reports total recorded calls, remaining count per route, and route queue cursors).
- Implemented `backend/replay/middleware.py` (`ReplayMiddleware`) as a pure ASGI middleware (`scope/receive/send`):
  - Dynamic environment evaluation: calls `is_record_enabled()` and `is_replay_enabled()` at runtime so live environment toggles (e.g. `monkeypatch` in tests or dynamic runtime flags) take immediate effect.
  - Inert mode: when neither `DEMO_RECORD` nor `DEMO_REPLAY` is enabled, passes all requests downstream untouched.
  - Path filtering: intercepts only `/api/*` routes; non-`/api/` routes (e.g. `/health`, static frontend files) pass downstream untouched.
  - Built-in control endpoints:
    - `GET /api/replay/status`: returns `{mode, recorded_calls, remaining, routes}`.
    - `POST /api/replay/reset`: resets queue cursors back to turn 0 and returns `{"status": "ok", "message": "Replay cursors reset"}`.
  - Replay mode (`DEMO_REPLAY=1`): completely suppresses downstream application execution for `/api/*` routes; returns next recorded response with restored base64 audio. Returns `409 Conflict` (`{"error": "Replay exhausted", "detail": "..."}`) when queue is exhausted.
  - Record mode (`DEMO_RECORD=1`): intercepts only JSON responses (`content-type: application/json`), streaming chunk accumulation, and writes to `ReplayStore` protected by an `asyncio.Lock`. Streaming / non-JSON responses pass through untouched without recording.
- Verified and configured `backend/replay/__init__.py` to export `ReplayStore`, `ReplayMiddleware`, `is_replay_enabled`, and `is_record_enabled` with dynamic `os.getenv` checks and safe fallback to `config.py` defaults.
- Authored `backend/demo_cache/replay/README.md` documenting offline replay architecture, directory layout, step-by-step recording instructions at integration (Hour 20 / Checkpoint 5), and offline demo replay execution with Wi-Fi disabled.
- Created `backend/tests_m2/test_b6_replay.py` with 8 comprehensive unit and integration tests covering:
  - 5-call recording session on a representative toy FastAPI app (`POST /api/ingest-repo`, 3x `POST /api/viva/turn` with audio, `GET /api/report/{id}`).
  - Replay session with downstream handlers swapped for ASGI callables that raise `RuntimeError`, proving zero app calls during replay.
  - Exact response matching including rehydrated audio payloads.
  - 409 Conflict upon queue exhaustion.
  - Replay reset via `POST /api/replay/reset` allowing repeated demo playthroughs.
  - Passthrough of non-`/api/` routes (`/health`) and inert mode untouched execution.
  - Passthrough of non-JSON / streaming responses (`/api/plain-text`) without recording.
  - Deeply nested audio extraction and rehydration.
  - Concurrent recording with `asyncio.Lock` coordination via `httpx.AsyncClient`.

## Public interface as implemented
- `backend/replay/store.py`:
  - `class ReplayStore`:
    - `__init__(self, replay_dir: str = REPLAY_DIR) -> None`: Initializes store targeting `replay_dir` (honors `os.getenv("REPLAY_DIR")` if default is passed).
    - `record(self, method: str, path: str, status: int, body: dict) -> None`: Appends interaction to `session.jsonl` and extracts `audio_base64` fields to `audio/<n>.mp3`.
    - `next(self, method: str, path: str) -> Optional[tuple[int, dict]]`: Returns `(status, rehydrated_body)` from queue or `None` if exhausted.
    - `reset(self) -> None`: Rewinds all queue playback cursors to 0.
    - `status(self) -> dict`: Returns `{recorded_calls: int, remaining: dict[str, int], routes: dict}`.
    - `clear(self) -> None`: Deletes `session.jsonl`, all audio files, and resets cursors.
    - `normalize_path(self, path: str) -> str`: Normalizes parameterized paths (`/api/report/xyz` -> `/api/report/{id}`).
- `backend/replay/middleware.py`:
  - `class ReplayMiddleware`:
    - `__init__(self, app: Any) -> None`: Pure ASGI middleware constructor taking only `(self, app)`.
    - `async __call__(self, scope: dict[str, Any], receive: Callable, send: Callable) -> None`: Pure ASGI handler.
- `backend/replay/__init__.py`:
  - `def is_replay_enabled() -> bool`: Returns `True` if `DEMO_REPLAY` is truthy in environment.
  - `def is_record_enabled() -> bool`: Returns `True` if `DEMO_RECORD` is truthy in environment.
  - Re-exports: `ReplayStore`, `ReplayMiddleware`, `is_replay_enabled`, `is_record_enabled`.
