# Handoff A2 — AST indexer + RepoIndex helpers

## Project in one paragraph
VivaVoce is a spoken-plus-text technical viva examiner for GitHub code repositories (Mode A) and research paper PDFs (Mode B) climbing Bloom's taxonomy from recall up to live sandbox mutation fixes. M2 owns ingestion, sandbox execution, and demo reliability: parsing repositories into AST symbols and line-numbered source, calculating git-blame authorship, parsing PDFs into concept graphs and Mermaid diagrams, executing student code safely in a timeout-enforced pytest sandbox, and ensuring 100% offline demo survivability through pre-baked caches and ASGI replay middleware.

## What this task did
- Fully implemented `index_repo_path` in `backend/ingestion/repo_parser.py`:
  - Discovers all candidate `.py` files across the repo while honoring skip directories (`.git`, `venv`, `.venv`, `node_modules`, `build`, etc.) and symlinks, returning a POSIX-normalized, alphabetically sorted `file_tree` and `total_py_files`.
  - Integrates `rank_python_files` to select the top `MAX_INDEXED_FILES` (15); sets `truncated = True` whenever candidate count exceeds the maximum.
  - Extracts full AST details per file: functions, async functions, and methods with accurate `qualname` (`Class.method`, `outer.inner`), `kind` (`function`, `async_function`, `method`), arguments (including `*args`, `**kwargs`, kw-only, posonly), docstrings (stripped and truncated to first 300 characters), line ranges (`line_start` including decorators, `line_end`), and calls (deduped, max 30, isolated to enclosing scope without recursing into nested definitions).
  - Extracts class definitions and module-level `UPPER_CASE` constants (using `ast.unparse` truncated to <= 80 characters, with exact line numbers).
  - Extracts imported modules in appearance order (`imports`).
  - Safely handles syntax errors by retaining the file with full `content` and `line_count` while leaving function, class, constant, and import lists empty.
  - Computes `commit_sha` via `git rev-parse HEAD` (empty string if not a git repository) and deterministic 12-character hex `repo_id` (`sha256(f"{source_url}:{commit_sha}")[:12]`).
- Implemented `clone_and_index_repo` in `backend/ingestion/repo_parser.py`: validates GitHub URL, clones to a unique directory under `WORK_DIR`, and indexes the cloned repository (accepting keyword-only `use_cache=True` ready for A5 demo cache wiring).
- Preserved all existing working functions and hardenings in `repo_parser.py` from Task A1 (`validate_github_url`, `clone_repo`, `cleanup_repo`, `rank_python_files`, GCM and prompt suppression, Windows read-only git deletion).
- Implemented all five `RepoIndex` helper methods in `backend/ingestion/models.py`:
  - `get_file(path)`: Normalizes posix/Windows paths and relative prefixes to retrieve `FileIndex`.
  - `identifiers(limit=60)`: Returns prioritized, deduped identifiers (functions, classes, constants, module names) in ranked-file order for M3's speech-to-text prompt.
  - `numbered_source(path, start, end)`: Returns right-aligned line numbers formatted as `'  12 | code'` with start/end clamped to valid file lines.
  - `find_function(path, line)`: Returns the innermost `FunctionInfo` enclosing the specified line number.
  - `snap_range(path, start, end)`: Citation guard implementing all four rules (Rule 1: exact containment in a function -> unchanged; Rule 2: partly outside -> clamp to that function; Rule 3: outside any function -> nearest function by distance; Rule 4: unknown path -> top-ranked file's first function). Clamps all inputs so ranges never escape the file.
- Built comprehensive test suite in `backend/tests_m2/test_a2_index.py` with 14 test cases covering all requirements, including a fixture repo with classes, async functions, nested functions, decorators, constants, and a syntax-error file.
- Measured indexing performance on a 15-file repository with 17 candidates: completed in **84.8 ms** (far under the 1.0 s requirement).

## Public interface as implemented
- `ingestion.repo_parser.index_repo_path(repo_path: str, source_url: str = "local") -> RepoIndex`
  Indexes local Python repository directory, extracts AST metadata, builds sorted `file_tree`, and computes `repo_id`/`commit_sha`.
- `ingestion.repo_parser.clone_and_index_repo(github_url: str, *, use_cache: bool = True) -> RepoIndex`
  Validates URL, clones repository, and returns parsed `RepoIndex`.
- `ingestion.models.RepoIndex`:
  - `get_file(self, path: str) -> Optional[FileIndex]`
  - `identifiers(self, limit: int = 60) -> list[str]`
  - `numbered_source(self, path: str, start: Optional[int] = None, end: Optional[int] = None) -> str`
  - `find_function(self, path: str, line: int) -> Optional[FunctionInfo]`
  - `snap_range(self, path: str, start: int, end: int) -> tuple[str, int, int]`
