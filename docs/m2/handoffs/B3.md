# Handoff B3 — PDF text + section extraction, sample paper

## Project in one paragraph
VivaVoce is a spoken-plus-text technical viva examiner for GitHub code repositories (Mode A) and research paper PDFs (Mode B) climbing Bloom's taxonomy from recall up to live sandbox mutation fixes. M2 owns ingestion, sandbox execution, and demo reliability: parsing repositories into AST symbols and line-numbered source, calculating git-blame authorship, parsing PDFs into concept graphs and Mermaid diagrams, executing student code safely in a timeout-enforced pytest sandbox, and ensuring 100% offline demo survivability through pre-baked caches and ASGI replay middleware.

## What this task did
- Implemented `extract_sections` in `backend/ingestion/pdf_parser.py` using PyMuPDF (`pymupdf`) via `get_text("dict")` inspecting font sizes, font weights (bold flags `flags & 16` and font names), and bounding boxes.
- Implemented column-aware reading order detection: correctly sequences single-column documents and two-column research papers without interleaving left/right columns.
- Implemented title extraction on Page 1: detects the largest font size among text spans on page 1, aggregating contiguous lines into a clean document title, with fallback for documents without larger title styling.
- Implemented section heading detection: captures numbered headings (`NUMBERED_HEADING_RE`: arabic `1`, `2.1`, roman `I.`, `II.`), known unnumbered academic headings (`KNOWN_HEADINGS`: Abstract, Introduction, Method, Evaluation, Limitations, References, etc.), and noticeably larger/bold headings (`max_size >= body_size + 1.2` or bold body-sized text), while filtering out page numbers, running headers/footers, and figure/table captions.
- Implemented per-page fallback: when a document contains no headings (e.g. unformatted narrative text), it produces exactly one section per page titled `Page 1`, `Page 2`, etc., with 1-based page ranges.
- Implemented text de-hyphenation across line breaks (`word- \n word -> wordword` for ascii and unicode hyphens) and whitespace normalization across `full_text` and each `section.text`.
- Implemented strict error handling raising `IngestionError` with friendly, informative messages for:
  1. Corrupted/unreadable bytes
  2. Empty bytes / empty streams
  3. Password-encrypted PDFs (`doc.is_encrypted` or `doc.needs_pass`)
  4. Scanned or image-only PDFs with no extractable text layer (`total_alphanumeric < 10`)
- Created `backend/demo_cache/build_sample_paper.py`: a deterministic `fpdf2` generator producing a 3-page fictional lab report titled *"Adaptive Spaced Repetition with Peer Matching"* (authors: Aman Verma, Priya Nair, Rohan Gupta; affiliation: Department of Computer Science, National Institute of Technology). Uses built-in fonts only (`Helvetica`, `Helvetica-Bold`, `Helvetica-Oblique`) and a fixed timestamp (`2026-01-01 00:00:00`) ensuring byte-for-byte deterministic output (8,586 bytes).
- Executed `build_sample_paper.py` to create `backend/demo_cache/sample_paper.pdf`.
- Defined 12 structured sections in the sample paper: Abstract, 1 Introduction, 2 Method, the 6 clear sequential method stages (2.1 Concept Knowledge Graph Construction, 2.2 Dynamic Memory Decay Modeling, 2.3 Peer Complementarity Scoring, 2.4 Synchronous Pairing and Session Scheduling, 2.5 Collaborative Question Generation, 2.6 Dual-Feedback Performance Update), 3 Evaluation, 4 Limitations, and References.
- Created `backend/tests_m2/test_b3_pdf_extract.py` with 10 comprehensive unit tests verifying sample paper extraction, title accuracy, method stage sequencing, per-page fallback, garbage/empty/encrypted/scanned error handling, line break de-hyphenation, and Roman numeral headings.
