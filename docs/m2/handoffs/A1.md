VivaVoce is a spoken-plus-text technical viva examiner for GitHub code repositories (Mode A) and research paper PDFs (Mode B) climbing Bloom's taxonomy from recall up to live sandbox mutation fixes. M2 owns ingestion, sandbox execution, and demo reliability: parsing repositories into AST symbols and line-numbered source, calculating git-blame authorship, parsing PDFs into concept graphs and Mermaid diagrams, executing student code safely in a timeout-enforced pytest sandbox, and ensuring 100% offline demo survivability through pre-baked caches and ASGI replay middleware.

## What this task did
- Fully implemented `validate_github_url` in `backend/ingestion/repo_parser.py`: enforces `https://github.com/<owner>/<repo>` format with optional `.git` and trailing slash; rejects SSH, `file://`, non-GitHub hosts, query params, fragments, extra path segments, and empty components with friendly `IngestionError` messages.
- Fully implemented `clone_repo` in `backend/ingestion/repo_parser.py`: clones repos via subprocess `git clone`, suppressing interactive prompts with `GIT_TERMINAL_PROMPT=0`, respecting `CLONE_TIMEOUT_S`; performs an unauthenticated size check via `https://api.github.com/repos/<owner>/<repo>` doing a full clone if size <= `FULL_CLONE_MAX_KB` (20 MB) or `--depth CLONE_DEPTH` (50) otherwise, with any API failure cleanly falling back to shallow clone; creates unique destination folders under `WORK_DIR`; translates 404, private repo, timeout, and git failures into `IngestionError`.
- Fully implemented `cleanup_repo` in `backend/ingestion/repo_parser.py`: Windows-safe recursive removal using `onexc`/`onerror` handlers that clear read-only file/directory flags (`stat.S_IWRITE | stat.S_IWUSR`) on `.git` objects, with secondary pass safety; idempotent on nonexistent or empty paths.
- Fully implemented `rank_python_files` in `backend/ingestion/repo_parser.py`: scans `.py` files in `repo_path`, strictly pruning `.git`, `venv`, `.venv`, `env`, `.env`, `node_modules`, `site-packages`, `migrations`, `build`, `dist`, `__pycache__`, `.tox`, `.nox`, `.pytest_cache`, `.mypy_cache`, and files with line count > `MAX_FILE_LINES` (2000) or symlinks; counts how many distinct *other* repo files import each module via AST parsing of absolute imports (`import pkg.mod`, `from pkg.mod import x`, `from pkg import mod`), relative imports (`from . import mod`, `from .mod import x`, `from ..mod import x`), and sibling imports; scores each file as `score = line_count + 40 * import_count`; categorizes and places all test files (`tests/`, `test_*.py`, `*_test.py`, `conftest.py`) strictly last; returns POSIX relative paths.
- Implemented comprehensive test suite in `backend/tests_m2/test_a1_clone.py` with 38 test cases across URL validation, fixture-based file ranking, Windows read-only cleanup, mocked clone scenarios, and a live `@pytest.mark.network` clone test.

## Public interface as implemented
- `ingestion.repo_parser.validate_github_url(url: str) -> tuple[str, str]`
  Accepts valid GitHub URLs; returns `(owner, repo)`; raises `IngestionError` on invalid URLs.
- `ingestion.repo_parser.clone_repo(github_url: str, dest_dir: Optional[str] = None) -> str`
  Clones repo into unique directory under `WORK_DIR` (or `dest_dir`); returns absolute local path; raises `IngestionError` on timeout, private/404, or git failure.
- `ingestion.repo_parser.rank_python_files(repo_path: str) -> list[tuple[str, int, int]]`
  Returns sorted `list[tuple[str, int, int]]` of `(posix_rel_path, line_count, import_count)` sorted by importance score with tests last; raises `IngestionError` if directory does not exist.
- `ingestion.repo_parser.cleanup_repo(path: str) -> None`
  Safely removes repo directory and read-only `.git` files on Windows; never raises.
