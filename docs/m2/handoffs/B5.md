## What this task did
- Implemented `verify_excerpt(excerpt: str, full_text: str) -> tuple[str, bool]` in `backend/ingestion/pdf_parser.py`:
  - `_normalize_text`: Unifies smart quotes (`“`, `”`, `‘`, `’`, `«`, `»`) to standard ASCII quotes, normalizes unicode dashes and hyphens (`—`, `–`, `−`, `‐`) to standard `-`, and collapses consecutive whitespace characters.
  - Verbatim check: If normalized excerpt appears as a substring anywhere within normalized full text, returns `(excerpt.strip(), True)`.
  - Sentence splitter `_split_into_sentences`: Splits across paragraph blocks (`\n+`) and sentence-ending punctuation (`[.!?]`), protecting periods within decimals (e.g. `3.14`, `2.1`), Latin abbreviations (`e.g.`, `i.e.`, `et al.`), author initials (`A. Verma`), and common abbreviations (`Fig.`, `Sec.`, `Dr.`, `Prof.`, `vs.`, `etc.`).
  - Fuzzy matcher: Computes `difflib.SequenceMatcher.ratio()` across all individual sentences and all 2-sentence sliding windows (`sentences[i] + " " + sentences[i+1]`), selecting the highest-ratio real candidate from the text and returning `(closest_real_text, False)`.
- Implemented paper disk caching:
  - `load_cached_paper(pdf_bytes: bytes) -> Optional[PaperIndex]`: Computes `paper_id = hashlib.sha256(pdf_bytes).hexdigest()[:16]` and deserializes `demo_cache/papers/<paper_id>.json` using `PaperIndex.model_validate_json(...)`. Returns `None` if missing, unreadable, or invalid.
  - `save_cached_paper(index: PaperIndex) -> None`: Serializes `PaperIndex` via `model_dump_json(indent=2)` and writes to `demo_cache/papers/<index.paper_id>.json`, creating parent directories if necessary.
- Implemented end-to-end `parse_research_paper(pdf_bytes: bytes, *, use_gemini: bool = True, use_cache: bool = True) -> PaperIndex`:
  - Cache hit path: If `use_cache=True` and cache file exists, loads paper index, sets `source = "cache"`, and returns in ~15 ms (well under the 50 ms target).
  - Fresh parsing path:
    1. Extracts sections and full text via `extract_sections` (raises `IngestionError` only if PDF is unreadable, encrypted, empty, or image-only).
    2. Generates concept graph using `build_concept_graph` (if `use_gemini=True`) or `_heuristic_concept_graph` (if `use_gemini=False`). Gemini exceptions are caught and automatically fall back to heuristic (Gemini failure never raises).
    3. Verifies every node excerpt with `verify_excerpt`, setting `node.excerpt_verified = is_exact` and updating `node.excerpt` with the verified real text.
    4. Assembles `excerpts` dictionary mapping each node ID (`N1`..`Nk`) to its verified excerpt.
    5. Builds Mermaid diagram string in code via `build_mermaid`.
    6. Saves resulting `PaperIndex` to disk via `save_cached_paper`.
- Executed `parse_research_paper` on `backend/demo_cache/sample_paper.pdf`, producing `backend/demo_cache/papers/73cbee6fbc268346.json` (27,865 bytes) which is committed for offline demo survivability.
- Created `backend/tests_m2/test_b5_paper.py` containing 15 comprehensive unit and integration tests verifying verbatim sentence matching, normalized quote/dash handling, verbatim substring detection, paraphrase fuzzy matching, typo resilience, sentence splitting abbreviation safety, 2-sentence window matching, empty input handling, cache round-trip, cache hit performance (< 50 ms), offline heuristic parsing, Gemini failure resilience, unreadable PDF error handling, and live Gemini API execution.
