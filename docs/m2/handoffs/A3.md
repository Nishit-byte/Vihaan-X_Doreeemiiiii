## What this task did
- Fully implemented `blame_file` in `backend/ingestion/git_blame.py`:
  - Executes `git blame --line-porcelain -w` per file with a 10 s per-file subprocess timeout.
  - Passes `GIT_TERMINAL_PROMPT=0`, `GCM_INTERACTIVE=never`, `GIT_ASKPASS=echo`, and `stdin=DEVNULL` to prevent hangs or interactive Windows dialogs.
  - Parses `line` (final line number, 1-based), `author`, `email` (stripping wrapping `<>`), and `commit` (SHA).
  - Skips uncommitted lines (`author == "Not Committed Yet"` or commit SHA `0000000...` or email `not.committed.yet`).
  - Safely handles missing files, untracked files, and empty files (returns empty list `[]`); raises `IngestionError` if the repo directory does not exist.
- Fully implemented `normalize_identity` in `backend/ingestion/git_blame.py`:
  - Uses lower-cased email as the primary identity key.
  - Normalizes GitHub noreply emails (`12345+username@users.noreply.github.com` or `username@noreply.github.com`) to `username`.
  - Applies `alias_map` to both email and author name candidates (with 1-level transitive resolution).
  - Falls back gracefully to `name` or email user prefix.
- Implemented repo-wide identity aggregation (`_build_author_identities`):
  - Resolves an author's display name to the most frequent spelling for their identity key across all blamed lines.
  - Selects the canonical email as the most frequent email seen for that key.
- Fully implemented `extract_author_map` in `backend/ingestion/git_blame.py`:
  - Maps each author to the list of `OwnedSymbol` objects they own.
  - Attributes each AST function to the author with the most lines in its range (`[fn.line_start, fn.line_end]`); ties are broken by the author with the earliest line number in that function.
  - Computes `share = round(lines_owned / function_lines, 4)`.
  - Groups loose lines outside functions per file under `symbol=None` with `lines_owned` and `share` relative to loose lines in that file.
  - Automatically falls back to A2's `index_repo_path` if `index is None` (or on-the-fly AST parsing if an indexed file was omitted).
  - Returns each author's symbols sorted by `(file_path, line_start)`.
- Fully implemented `compute_authorship_stats` in `backend/ingestion/git_blame.py`:
  - Aggregates blamed line counts across all indexed files.
  - Calculates author `share_of_lines` relative to total lines, sorted descending by share.
  - Ensures shares sum to 1.0 (±0.001) by adjusting rounding remainder on the top contributor.
  - Explicitly documents the shallow-clone limitation (boundary commits absorb older history, P2-2.9) in the docstring.
- Fully implemented `list_authors` in `backend/ingestion/git_blame.py`:
  - Returns authors sorted descending by total lines owned across all symbols.
- Built comprehensive test suite in `backend/tests_m2/test_a3_blame.py` with 8 test cases:
  - Git repository fixture in `tmp_path` configured with 3 authors using `GIT_AUTHOR_*` and `GIT_COMMITTER_*` env vars.
  - Merges one author using two name spellings ("Aman Verma", "Aman V.") and two emails ("aman@example.com", "aman.work@example.com") via `alias_map`.
  - Tests GitHub noreply email normalization ("priya-dev").
  - Verifies function ownership, tie-breaking by earliest line, share calculations, and `symbol=None` loose lines.
  - Verifies descending authorship stats summing to 1.0, email stripping, and docstring documentation.
  - Verifies `list_authors` descending ordering and uncommitted line skipping.

## Public interface as implemented
- `ingestion.git_blame.blame_file(repo_path: str, file_path: str) -> list[dict]`
  Runs `git blame --line-porcelain -w` with 10 s timeout; parses `line`, `author`, `email`, `commit`; skips uncommitted lines; returns `list[dict]`.
- `ingestion.git_blame.normalize_identity(name: str, email: str, alias_map: Optional[dict[str, str]] = None) -> str`
  Normalizes author identity by lower-cased email key, GitHub noreply extraction, and alias mapping.
- `ingestion.git_blame.extract_author_map(repo_path: str, files: list[str], index: Optional[RepoIndex] = None, alias_map: Optional[dict[str, str]] = None) -> dict[str, list[OwnedSymbol]]`
  Maps author to owned functions (most lines in range, tie -> earliest line) and loose lines (`symbol=None`); auto-indexes with A2 when `index is None`.
- `ingestion.git_blame.compute_authorship_stats(repo_path: str, files: list[str], alias_map: Optional[dict[str, str]] = None) -> list[AuthorStat]`
  Computes authorship breakdown and shares across all indexed files, sorted descending, shares summing to 1.0 (±0.001); documents shallow clone limitation (P2-2.9).
- `ingestion.git_blame.list_authors(author_map: dict[str, list[OwnedSymbol]]) -> list[str]`
  Returns authors sorted descending by total lines owned.
